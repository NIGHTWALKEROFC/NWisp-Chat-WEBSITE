Security

Found something that puts someone's privacy at risk?

This page is separate from the regular Updates page on purpose — Updates is for new features, this page is only for actual security problems: what was found, how it was fixed, and credit to whoever reported it.

Report it privately first

Please don't post it publicly before reaching out

If you find a bug that could put someone's messages, account, or privacy at risk, please email it to me directly before posting about it anywhere public — social media, forums, group chats, anywhere. That gap gives me a real chance to fix it before anyone else can use it against someone. Once it's fixed, it'll be listed below along with credit to you for finding it (or left anonymous, if you'd rather).
