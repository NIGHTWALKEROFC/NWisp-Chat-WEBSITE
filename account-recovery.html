Trust & safety

Lost access, or think someone else got in?

Pick whichever one matches what's happening. Each one is a real, working flow already inside the app — this page just explains what it does and why, in plain terms.

I forgot my password

Use "Forgot password?" on the sign-in screen. Enter the email your account uses, and we'll send a reset link to that address.

  1. Tap "Forgot password?" on the sign-in screen
  2. Enter your account email and submit
  3. Open the reset link from your email
  4. Set a new password and sign in with it

This only works if you still have access to that email account — see the last section on this page if you don't.

I think someone else signed into my account

NWisp Chat only allows one signed-in device at a time, and every sign-in is logged with an approximate location. Here's what to do:

  1. Open Settings → Account security and check "Recent activity" for a sign-in you don't recognize
  2. Change your password immediately — this signs the other device out right away, the same instant you do it
  3. Turn on "Require approval for new logins" so any future sign-in has to be approved from a device you already control, instead of instantly kicking you out
  4. If you think this happened through an actual bug or exploit, not just someone guessing a weak password, report it on the Security page instead of just changing your password

I forgot my app-lock PIN

App lock has its own "Forgot PIN?" option that goes through the same password-reset flow above — since you'd need to prove you're the account owner either way, it reuses the same email-link process rather than a separate one.

  1. On the app-lock screen, tap "Forgot PIN?"
  2. Follow the password-reset email link the same way as above
  3. Signing back in with your (possibly new) password clears the old PIN — you'll be asked to set a new one

I forgot my hidden-chats code

This is the one recovery flow that's deliberately not gentle — on purpose. Resetting a hide code always wipes the content it was protecting, rather than quietly showing it again. That's intentional: if this were a soft "turn hiding off" toggle, anyone holding your unlocked phone could just switch it off and read everything hidden behind it. Requiring your real password and typing a confirmation word makes that a lot harder to do to someone else's phone.

  1. Go to the hidden-chats reset option in Settings → Security
  2. Choose whether you're resetting the shared code (wipes every chat hidden under it) or one specific chat's own custom code (wipes just that one chat)
  3. Enter your account password to confirm it's really you
  4. Type RESET to confirm — this step exists so it can never happen by accident

There's no way to recover the wiped content afterward — it's the same as clearing a chat. If you just want to see what's hidden and remember the code, you don't need this at all — only use it if the code is genuinely gone.

I don't have access to my email either

All of the flows above rely on your account email, since we have no phone number on file and no way to verify identity any other way without it. If that email is also gone, reach out directly and explain the situation — every case like this has to be handled individually, and there's no guaranteed outcome, but it's worth asking.
